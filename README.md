
# Database Metadata and Schema Analysis

## Overview
This project consists of SQL queries that explore and extract metadata from a relational database schema using the SQL `information_schema`.

### Key Concepts
- Metadata querying using SQL `information_schema`.
- Analysis of tables, columns, and constraints.
- Ensuring database integrity through schema insights.

## Files Included
- `queries/`: Contains SQL queries designed to retrieve metadata details such as table names, column types, constraints, etc.

## Example Queries
- Retrieve table details and comments.
- List nullable columns and their data types.
- Identify unique and referential constraints.

## Technologies
- SQL (Information Schema)
- Database schema management
